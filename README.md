# Mini Laboratório de Áudio em Tempo Real 🎙️

Projeto desenvolvido em Python para a disciplina de **Processamento Digital de Sinais**.

## 📌 Funcionalidades
- Gravação de áudio pelo microfone.
- Visualização do sinal no tempo.
- Processamentos:
  - FFT (Transformada Rápida de Fourier).
  - Filtro Passa‑Baixa (com frequência de corte ajustável).
  - Espectrograma.
- Reprodução do áudio original e do áudio filtrado.
- Interface gráfica amigável com sliders dinâmicos.
